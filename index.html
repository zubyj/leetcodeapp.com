Questions

How do I use it?

Install it, open any LeetCode problem, and click the new Explained tab next to Submissions. Pin the extension to use the AI features and see your progress.

Does it collect any data?

No. Settings, the problem dataset, and your submission history are stored in your browser and never sent to us. The only network requests are to fetch solution code from GitHub and, if you use the AI buttons, to send the problem text to the model that answers. Details in the privacy policy.

Why does it ask for permission to read tabs?

The popup reads the active tab's URL and title to know which problem you're on. That's the only use.

Where do the videos, solutions, and company data come from?

Videos are found through the YouTube Data API. Solution code is fetched live from the open-source NeetCode repository. Company tags come from the community-maintained liquidslr dataset, and Elo ratings from zerotrac.

Is it free?

Yes, and open source under the MIT license. Contributions are welcome on GitHub.

Something broke. Who do I tell?

Email zubydevelops@gmail.com or open an issue on GitHub. LeetCode changes its page often, and a quick report gets it fixed faster than a review.
